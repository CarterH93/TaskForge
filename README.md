#  Task Forge
**Technologies:** Swift, SwiftUI, SwiftData (SQL), Cloudkit
- Developed an app that syncs and fetches remote tasks from Canvas and Google Calendar
- Integrated task and reminder storage in a cloud-synced Swift Data (SQL) database
- Implemented push notifications to the user's device
- Created an automatic spaced reminder scheduling system that increases task completion

More information at this website: 
[TaskForge](https://taskforgeapp.com/)
